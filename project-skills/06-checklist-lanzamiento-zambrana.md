# Checklist Lanzamiento Zambrana

## Cuando usarla

Usar esta skill antes de publicar la web o antes de entregar una version final para revision comercial.

## Objetivo

Confirmar si la web esta lista para salir a produccion, separando bloqueantes de observaciones.

## Reglas

- No modificar archivos durante la checklist salvo pedido explicito.
- Revisar como usuario final y como mantenedor del stock.
- Priorizar problemas que afecten consulta, confianza, carga, mobile o stock.
- Separar errores reales de mejoras deseables.
- Cerrar con estado Verde, Amarillo o Rojo.

## Checklist

- Home comunica claro que es Zambrana Automotores.
- Hero carga bien y tiene CTA visible.
- Catalogo abre correctamente.
- Filtros funcionan.
- Ordenamiento funciona.
- Cards muestran foto, marca, modelo, año, kilometros, combustible, precio o consultar.
- Fichas individuales cargan desde cada card.
- Fichas muestran galeria, datos y CTA.
- Imagenes de portada existen.
- Galerias no tienen imagenes rotas.
- WhatsApp flotante funciona.
- WhatsApp de ficha incluye vehiculo especifico.
- WhatsApp general tiene mensaje comercial claro.
- Formularios envian o muestran error claro.
- Mapa y ubicacion cargan.
- Horarios y direccion estan visibles.
- Mobile no corta textos, cards ni botones.
- Filtros mobile son usables.
- Consola sin errores relevantes.
- SEO basico: title, meta description, H1 y textos principales.
- Performance basica: imagenes y videos no bloquean la experiencia.
- Stock actualizado.
- Vehiculos vendidos, reservados y disponibles estan bien representados.
- Vehiculos vendidos no aparecen como oportunidad destacada.
- CTA de financiacion existe o esta claramente resuelto si corresponde.

## Estados de cierre

- Verde: listo para publicar.
- Amarillo: publicable con observaciones.
- Rojo: no conviene publicar todavia.

## Formato de respuesta esperado

- Estado final: Verde / Amarillo / Rojo.
- Resumen ejecutivo.
- Bloqueantes.
- Observaciones importantes.
- Mejoras futuras.
- Validaciones realizadas.
- Proximo paso recomendado.
