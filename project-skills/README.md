# Skills locales Zambrana Automotores

## Que son

Estas skills son guias locales de trabajo para futuros cambios en la web de Zambrana Automotores. Sirven para que Codex trabaje de forma quirurgica, ordenada y sin romper catalogo, WhatsApp, fichas, diseño ni mantenimiento del stock.

## Cuando usarlas

Usarlas antes de cualquier cambio sobre home, catalogo, fichas de vehiculos, `vehicles.js`, imagenes, formularios, WhatsApp, SEO, responsive o preparacion de lanzamiento.

## Regla principal

Antes de modificar, diagnosticar. Primero leer el estado real del proyecto, detectar archivos implicados, riesgos y validaciones necesarias. Despues recien proponer o aplicar cambios, si el usuario lo pide.

## Prioridad del proyecto

La web debe ser rapida, simple, comercial y facil de mantener. El objetivo principal es generar consultas reales, especialmente por WhatsApp, sin agregar complejidad innecesaria.

## Reglas generales

- No crear panel, admin, backend, login ni base de datos salvo pedido explicito.
- No refactorizar de mas.
- No cambiar arquitectura si una edicion puntual resuelve el problema.
- No tocar catalogo, fichas, WhatsApp o assets fuera del alcance pedido.
- No inventar datos comerciales faltantes.
- Mantener el estilo Zambrana: minimalista, rojo, negro y blanco, tipografia Poppins, comercial, limpio y directo.
- Validar siempre home, catalogo, ficha individual y WhatsApp cuando el cambio pueda afectarlos.

## Skills disponibles

- `01-diagnostico-antes-de-cambiar.md`: revisar antes de tocar.
- `02-actualizar-stock-zambrana.md`: agregar, quitar o marcar vehiculos.
- `03-imagenes-vehiculos-zambrana.md`: revisar y preparar imagenes de vehiculos.
- `04-revision-comercial-zambrana.md`: evaluar venta, confianza y conversion.
- `05-whatsapp-conversion-zambrana.md`: revisar enlaces, mensajes y numero.
- `06-checklist-lanzamiento-zambrana.md`: control final antes de publicar.
